## About Me

I'm Ali — a Senior React Native Engineer who ships **cross-platform mobile apps end-to-end**: from native module integration and real-time systems to CI/CD pipelines and App Store releases.

I work best on **hard, unsolved problems** — the ones with no existing library, no Stack Overflow answer, and no in-house precedent. I'll go straight to source documentation and native code before settling for a workaround.

I use **AI-assisted development (Claude Code, Cursor)** daily — not as a novelty, but as a core part of how I plan, build, debug, and ship faster without cutting corners on quality.

When I'm offline you'll usually find me reading, hiking, cycling, or hopping between cafés with a laptop and too many tabs open. =)

**Highlights**

- Senior React Native Engineer building real-time, native-integrated mobile products
- Deep native work: patched native libraries and built custom Expo Config Plugins from scratch
- Full stack: React Native, Node.js, Nest.js, MongoDB, AWS
- AI-augmented engineering as a daily practice, not an experiment
- Reader, hiker, cyclist, and dedicated café-hopper
